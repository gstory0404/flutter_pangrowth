## 简介
flutter_pangrowth是一个可以帮助开发者直接引入穿山甲内容输出，为自己app无侵入快速引入小说、视频内容的插件。[体验demo](https://www.pgyer.com/sUQU)

## 集成步骤
#### 1、pubspec.yaml

```Dart
flutter_pangrowth: ^1.0.9
```

#### 2、引入
```Dart
import 'package:flutter_pangrowth/flutter_pangrowth.dart';
```
